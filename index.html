    원하는 학생을 원하는 자리에 고정하고, 떨어뜨릴 학생을 분리 그룹으로 묶어요. 이 화면의 내용은 학생 화면과 출력에 나오지 않아요.

    미리 지정한 학생이 있으면 랜덤 섞기 때 그 학생을 뺀 나머지만 자리가 바뀌어요.

    설정

    1. 연간시간표 가져오기

    연간시간표, 주간 시간표, 주간학습안내 모두 돼요. 한글(.hwp·.hwpx), 워드(.docx), PDF 파일을 고르거나, 한글·엑셀·나이스에서 표 전체를 복사해 아래 칸에 붙여넣으세요(Ctrl+V). 다시 넣으면 그 주만 새로 바뀌어요. 날짜가 있는 주간 시간표·주간학습안내를 넣으면 연간시간표의 그 주가 이걸로 바뀌어요.

    2. 시정표 (우리 학교 교시별 시간)

    학교마다 다르니 꼭 맞춰 주세요. 이 시간에 맞춰 지금·다음 시간을 보여 줘요.

    3. 시간표 고치기

    '매주 기본 시간표'는 연간시간표에 없는 주에 쓰여요. 칸을 고치면 바로 저장돼요.

    뽑기와 자리배치에 쓰는 우리 반 명단이에요. 성별(남·여)은 자리배치의 짝꿍 조건에 써요. 한글·PDF 명렬표 파일에서 가져오거나, 아래 표에 번호와 이름을 직접 쓰세요. 가져온 뒤에도 표에서 바로 고칠 수 있어요. 이름 없이 번호만 써도 번호로 뽑아요. 쓰는 대로 저장돼요.

    번호이름성별

    이 주소를 다른 선생님께 보내 주세요. 열어서 앱으로 설치하면 바로 쓸 수 있어요.

    • 오늘의 주제 ↻로 다른 주제를 뽑아요. 쓴 주제는 '사용 체크'하면 다시 나오지 않아요. '2줄 이상 쓰기'는 더블클릭해서 고쳐요.
    • 메모 · 우리반 규칙 카드를 눌러 바로 쓰면 저절로 저장돼요. 글자를 끌어서 고른 뒤 오른쪽 아래 Tt에서 색을 고르면 그 글자만 바뀌어요. 메모는 아래쪽 바 버튼을 누를 때마다 한 장씩 더 생겨요(더 만든 메모는 닫으면 지워져요).
    • 사진 '사진 넣기'로 사진을 고르세요. 사진 위에 마우스를 올리면 바꾸기·지우기 버튼이 나와요. 아래쪽 바 버튼을 누를 때마다 사진 카드가 한 장씩 더 생겨요.
    • 타이머 30초·1·3·5·10분을 고르거나, 가운데 시간(00:00)을 눌러 3:30처럼 직접 쓰고 '시작'. +1은 1분 더하기예요. 시간이 끝나면 소리가 나고 카드가 깜빡여요.
    • 뽑기 전체: 설정 → 명단에 우리 반 이름을 한 줄에 하나씩(숫자만 쓰면 번호로). 선택: 오른쪽 아래 '✎ 고르기'로 뽑을 사람만 골라요. 모둠: 오른쪽 아래에 모둠 수를 정해요. 직접입력: 오른쪽 아래 '✎ 쓰기'로 그때그때 뽑을 것을 써요. 순서: 명단 전체가 이름 구슬이 되어 긴 핀볼 코스(경사로·범퍼·도는 막대·쐐기)를 굴러 내려가요. 화면은 맨 앞 구슬을 따라 내려가고, 맨 아래 구멍으로 빠진 순서대로 1등부터 정해요. 한 번 뽑힌 것은 모두 뽑힐 때까지 다시 나오지 않고, '처음부터'로 다시 시작해요.
    • 미세먼지 '지역 설정'에서 '지금 위치로'를 누르거나 시·군 이름(예: 수원시)으로 찾으세요. Open-Meteo(무료 공개 자료)의 예보값이라 에어코리아 측정소 값과 조금 다를 수 있어요. 30분마다 새로 받아요.
    • 소음 측정 '측정 시작'을 누르고 마이크를 허락하면 소리 크기를 막대로 보여 줘요. 기준(검은 선)을 1초 넘게 넘으면 경고음이 나고 오늘 경고 횟수가 쌓여요. '🔔 경고'로 직접 경고를 줄 수도 있어요. 소리는 이 컴퓨터 안에서만 재고, 녹음하거나 보내지 않아요.
    • 화이트보드 ✏️ 펜을 누르면 색과 굵기를 골라 그려요. T 글상자는 누른 뒤 보드(사진 위도 돼요)를 클릭해 써요. 사진은 복사해서 Ctrl+V(또는 끌어다 놓기). 옮기기에서 사진·글상자·펜 선을 끌어 옮기고, 오른쪽 아래 파란 점으로 크기를 바꾸고(글상자는 글씨도 같이 커져요), 오른쪽 위 ✕나 Delete로 지워요. 빈 곳에서 끌어 네모를 그리면 그 안에 통째로 들어온 것이 함께 골라지고(조금 걸친 건 빠져요), Shift를 누른 채 여러 개를 눌러도 골라져요. '묶기'로 한 덩어리로 묶어요('풀기'로 다시 나눠요). 글상자는 두 번 클릭하면 고치고, 글상자를 고르면 위에 나오는 Tt로 글씨 크기·색을 바꿔요. 여러 개나 묶음은 점선 상자 오른쪽 아래 파란 점으로 한꺼번에 크기를 바꿔요. ↶나 Ctrl+Z로 되돌려요. 제목 줄 오른쪽 1~4 버튼으로 화이트보드를 4개까지 따로 써요.
    • 시간표 설정 → 시간표에서 연간시간표(한글 파일 또는 표 붙여넣기)와 시정표를 넣으면, 지금 몇 교시인지와 다음 시간을 알려 줘요. 표에 없는 주는 '매주 기본 시간표'를 써요.
    • 보드 카드 제목을 끌어 옮기고, 오른쪽 아래 모서리로 크기를 바꿔요. 옮긴 자리와 크기는 앱을 껐다 켜도 그대로예요. ✕를 누르면 보드에서 닫히고 아래쪽 바로 들어가요. 닫아도 적어 둔 내용은 남아요.
    • 아래쪽 바 보드에서 닫은 카드가 들어가요. 누르면 보드에 다시 나와요.
    • 자리배치 처음 한 번 설정 버튼에서 모양(분단: 혼자·짝꿍과 앉기와 분단 수 / 모둠: 모둠 인원 / 직접 그리기: 명단 인원만큼 자리를 고르고, 필요하면 '방향 돌리기'로 ㄷ자처럼 옆을 보게)과 짝꿍 조건(상관없이·이성끼리·동성끼리·성별 고르게, 이전 짝꿍과 같이 안 앉기)을 정하면 계속 유지돼요. 성별은 설정 → 명단에서 이름과 함께 정해요. 평소에는 '자동 자리배치'(한 자리씩 나타나요), 저장(오늘 날짜로), 출력만 누르면 돼요. 이름을 끌어 다른 자리에 놓으면 자리를 바꾸고, 칠판 옆 '상하전환'으로 위아래를 바꿔요. 대형을 만들면 많이 쓰는 공개 모둠으로 묶여요(혼자 앉기는 한 줄, 짝꿍은 4~6명). 미리보기에서 책상이나 모둠을 끌어 옮기고 '간격 맞추기'로 줄과 간격을 똑같이 맞춰요. 모둠을 바꾸려면 책상을 고르고(Shift+누르기, 빈 곳을 끌어 네모로) '모둠으로 묶기'를 눌러요. 혼자 앉기에서는 짝꿍 대신 모둠 성별 조건(상관없이·성별 고르게)을 골라요. 오른쪽 작은 별은 선생님 모드예요(고정, 분리, 기록). 분리에서 같이 앉으면 안 되는 학생을 비밀 그룹으로 묶고 1~4순위를 정해요(1순위를 가장 먼저 떨어뜨려요). 같은 그룹은 짝꿍·앞뒤·좌우·같은 모둠으로 앉지 않아요. 다 지킬 수 없으면 바로 앉히지 않고 먼저 물어봐요.
    • 로그인 설정 → 로그인에서 구글로 로그인하면 보드가 서버에 저장되고, 다른 컴퓨터에서 같은 계정으로 로그인하면 같은 보드가 나와요.
    • 준비물 시간표 카드 오른쪽 칸에 쓰면 저장돼요.
    • 창 옮기기 맨 위 줄을 잡고 끌어요. 창 크기는 모서리를 끌어 조절해요. 창이 좁으면 카드가 아래로 쌓여요.
    • 앱 설치 (Edge) 이 주소를 Edge로 열고 주소창 오른쪽 설치 아이콘을 눌러요. 안 보이면 … 메뉴 → 앱 → '이 사이트를 앱으로 설치'.
    • 앱 설치 (Chrome) 주소창 오른쪽 설치 아이콘, 또는 ⋮ 메뉴 → 전송, 저장, 공유 → '페이지를 앱으로 설치'.
    • 켤 때 자동 실행 (Edge) 주소창에 edge://apps 입력 → 이 앱의 … → '장치 로그인 시 시작'.
    • 저장 위치 메모, 규칙, 사진, 사용 기록은 모두 이 컴퓨터에만 저장돼요. 인터넷으로 보내지 않아요.

    구글 계정으로 로그인하면 이 보드(명단·메모·급훈·시간표·카드 배치·사진·화이트보드)가 서버에 저장돼요. 다른 컴퓨터에서 같은 계정으로 로그인하면 같은 보드가 나와요. 고칠 때마다 몇 초 뒤 저절로 저장돼요.

    로그아웃해도 이 컴퓨터의 보드는 그대로 남아요. 여럿이 쓰는 컴퓨터라면 로그아웃한 뒤 '초기화'에서 지워 주세요.

    주제 사용 기록을 모두 지우고, 모든 주제가 다시 나오게 해요. 메모·규칙·사진과 '2줄 이상 쓰기' 문구는 그대로 남아요.

    보드 카드의 자리와 크기를 처음처럼 되돌려요. 적어 둔 내용은 그대로예요.
